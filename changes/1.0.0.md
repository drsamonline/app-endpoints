**Endpoints 1.0.0 — the directory that answers the three questions.**

A new app: 2,214 public APIs, bundled offline, filterable by auth, CORS and HTTPS. The engine
(`docs/play/endpoints.js`) validates every filter against a fixed vocabulary and refuses an unknown
value with the vocabulary it accepts, instead of returning an empty list that cannot be told apart
from "nothing matches". Ranking runs first and filtering second, so narrowing never promotes a weak
hit. Pins are the only state, and a pin that cannot be written is reported as not kept.
